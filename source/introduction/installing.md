# 安装 Renode

Renode 框架的安装过程取决于作系统。请使用 [Renode 的 Github](https://github.com/renode/renode/releases/latest) 上提供的软件包。

完整的安装说明在 [Renode 项目 README](https://github.com/renode/renode/blob/master/README.md#installation) 中描述。
  
您还可以在 Docker 容器中运行 Renode - 有关如何执行此作的详细信息，请参阅 [README](https://github.com/renode/renode/blob/master/README.md#running-renode-in-a-docker-container) 。
  
有关如何从源安装 Renode 的说明（适用于高级用户），请参阅[从源构建 Renode](https://renode.readthedocs.io/en/latest/advanced/building_from_sources.html)。
